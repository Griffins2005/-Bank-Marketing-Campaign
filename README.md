# Bank Marketing Campaign Analysis and Prediction

This project presents an exploratory and predictive analysis of the **Bank Marketing Dataset**.
The dataset contains information about customers contacted during a marketing campaign and records whether they subscribed to a term deposit (`deposit = 1`) or not (`deposit = 0`).

The analysis includes:

* Data loading and overview
* Exploratory Data Analysis (EDA) with rich visualizations
* Feature distribution analysis
* A baseline **Logistic Regression model**
* Key findings and actionable recommendations

---

## Dataset

The dataset comes from the [UCI Bank Marketing Dataset](https://archive.ics.uci.edu/ml/datasets/bank+marketing) and is also available on Kaggle.
